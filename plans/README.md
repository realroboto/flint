## Unplanned findings (audited, real, below the cut — plan on request)

- **CI token hardening**: `.github/workflows/ci.yml` has no `permissions:`
  block; add top-level `permissions: contents: read`. Two lines. (security, S)
- **Installer edge trio** (correctness, S, rare systems): (a) `install.py`
  imports `pathlib` before its Python-version gate — a python2-only system
  gets a traceback instead of the clean "needs Python 3.6+" message; (b) a
  non-list `hooks.<event>` value in settings.json is silently replaced,
  inconsistent with the no-clobber stance in `load()`; (c) `install.ps1`
  accepts the Windows Store python stub (`Get-Command python` finds it, run
  fails confusingly).
- **Test label gap**: `test/test.sh` budget labels jump 13d → 13f. Cosmetic;
  renumber whenever a plan next touches that block.

## Findings considered and rejected (do not re-audit)

- **Parent-directory symlink bypass of the hook's `[ -L ]` check**: a
  symlinked directory containing a real `flint.md` evades the file-level
  check. A POSIX-portable path-component walk (macOS bash 3.2, dash, Git
  Bash) is disproportionate to the marginal threat beyond the already-fixed
  upstream class. Plan 001's empty-read guard covers the adjacent race.
- **TOCTOU between the `-s` check and the `head` read**: subsumed by plan
  001's encode-stage empty-input guard (race now ends in the loud marker).
- **Anchor re-injection into subagents / per-turn reinforcement for
  subagents**: settled maintainer decision — the 3-hook design stands.
- **Canary re-injection / ruleset ablation experiments**: previously declined
  by the maintainer (flint issues #1/#2 closed).
- **PowerShell hook port**: rejected by ADR 0002 — a second implementation
  duplicates every invariant; drift between copies is the bug class flint
  exists to kill.
- **Cowork ZIP packaging script**: the recipe is 4 documented shell lines in
  `desktop/README.md`; a script adds surface for no drift risk. YAGNI.
- **Release-tag debt**: none — `git diff v0.1.1..main -- flint.md
  hooks/flint-style.sh` is empty; AGENTS.md only requires a tag when hook or
  ruleset change.
- **Direction — plugin/marketplace distribution**: offered as a spike option;
  the maintainer selected the top-5 fixes only. Grounding and trade-off (a
  second install path re-imports parity/drift at the packaging layer) are in
  the audit summary; revisit only if third-party adoption becomes a goal.
- **Direction — release checksum manifest for consumers**: the one known
  consumer (vmCODE) already runs its own parity check. Not worth doing now.
